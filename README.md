# Trade-Network Centrality and International Climate Adaptation Finance

This repository contains the code used to reproduce the empirical analyses and main figures for the study on the relationship between countries' positions in the global trade network and their receipt of international climate adaptation finance.

The empirical analysis focuses on non-high-income recipient countries and combines country-year adaptation-finance data with annual trade-network centrality measures. The analysis covers the period from 2000 to 2024, subject to data availability and the estimation sample used in each specification.

The repository includes:

- **Stata code** for analytical-data transformations, econometric estimation, counterfactual analysis, heterogeneity analysis, moderation analysis, and robustness tests;
- **Python Jupyter notebooks** for producing the descriptive, geographical, network, regression-result, counterfactual, and moderation figures presented in the main text.

## Empirical analysis

The Stata code implements:

- baseline Poisson pseudo-maximum-likelihood (PPML) models;
- instrumental-variable estimation using a control-function PPML approach;
- gravity-model-based instruments;
- a seaborne-trade Bartik shift-share instrument;
- counterfactual reassignment across trade-centrality quartiles;
- separate analyses of bilateral and multilateral adaptation finance;
- heterogeneity analyses by recipient-country income group;
- moderation analyses for disaster exposure and political alignment;
- robustness tests using alternative moving-average windows, winsorised variables, lagged controls, and the exclusion of the COVID-19 period.

The reported results from the PPML and control-function PPML models are presented as average marginal effects where indicated in the code and manuscript.

## System requirements

### Stata

The econometric analysis is implemented in **Stata 18**. 

The following community-contributed Stata packages are required:

- `ppmlhdfe`
- `reghdfe`
- `ftools`
- `estout` (providing `eststo`, `estadd`, and `esttab`)
- `rangestat`
- `winsor2`
- `astile`

### Python

The Jupyter notebooks were created using:

* **Python 3.11.1**
* Jupyter Notebook or JupyterLab

The notebooks require the following Python packages:

* `pandas`
* `numpy`
* `matplotlib`
* `seaborn`
* `geopandas`
* `shapely`
* `adjustText`
* `openpyxl`
* `jupyter`

## Figure reproduction

The Jupyter notebooks reproduce the main figures as follows:

| Notebook                                | Figure reproduced                                                                                    |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `Fig.1a_climatefinancetrend.ipynb`      | Temporal trends in international climate finance                                                     |
| `Fig.1b_climatefinance_sankey.ipynb`    | Composition and flows of international climate finance                                               |
| `Fig.1cd_climatefinancemap.ipynb`       | Geographical distribution of adaptation finance                                                      |
| `Fig.2_centrality.ipynb`                | Countries' positions in the global trade network                                                     |
| `Fig.3_climatefinance_centrality.ipynb` | Descriptive relationship between adaptation finance and trade-network centrality                     |
| `Fig.4_Baseline_results.ipynb`          | Baseline, instrumental-variable, and counterfactual estimates                                        |
| `Fig.5_BilaMuti_Marginal.ipynb`         | Marginal effects for bilateral and multilateral adaptation finance and heterogeneity by income group |
| `Fig.6ab_moderation_disaster.ipynb`     | Conditional effects across levels of disaster exposure                                               |
| `Fig.6cd_moderation_idealpoint.ipynb`   | Conditional effects across levels of political alignment                                             |

The regression-based notebooks use processed regression outputs generated by the Stata analysis. File paths may need to be updated to match the local directory structure before the notebooks are executed.
