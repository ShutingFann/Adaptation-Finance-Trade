# Trade-Network Centrality and International Climate Adaptation Finance

This repository contains the Stata code used to analyse the relationship between countries’ positions in the global trade network and their receipt of international climate adaptation finance.

The empirical analysis focuses on non-high-income recipient countries and combines country-year adaptation-finance data with annual trade-network centrality measures. The current code covers observations from 2000 to 2024, subject to data availability and the estimation sample used in each model.

The analysis includes:

* baseline Poisson pseudo-maximum-likelihood models;
* instrumental-variable estimation using a control-function PPML approach;
* gravity-model-based instruments;
* a seaborne-trade shift-share instrument;
* counterfactual reassignment across centrality quartiles;
* bilateral and multilateral adaptation-finance outcomes;
* heterogeneity by recipient-country income group;
* moderation analyses for disaster exposure and political alignment;
* robustness tests using alternative moving-average windows, winsorised variables, lagged controls, and the exclusion of the COVID-19 period.
