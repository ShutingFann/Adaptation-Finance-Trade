# Trade-Network Centrality and International Climate Adaptation Finance

This repository contains the code used to reproduce the empirical analyses and main figures for the study on the relationship between countries’ positions in the global trade network and their receipt of international climate adaptation finance.

The empirical analysis focuses on non-high-income recipient countries and combines country-year adaptation-finance data with annual trade-network centrality measures. The analysis covers the period from 2000 to 2024, subject to data availability and the estimation sample used in each specification.

The repository includes:

- **Stata code** for data processing, econometric estimation, counterfactual analysis, and robustness tests;
- **Python Jupyter notebooks** for producing the descriptive, network, regression-result, and moderation figures presented in the main text.

## Empirical analysis

The Stata code implements:

- baseline Poisson pseudo-maximum-likelihood models;
- instrumental-variable estimation using a control-function PPML approach;
- gravity-model-based instruments;
- Bartik shift-share instrument;
- counterfactual reassignment across trade-centrality quartiles;
- separate analyses of bilateral and multilateral adaptation finance;
- heterogeneity analyses by recipient-country income group;
- moderation analyses for disaster exposure and political alignment;
- robustness tests using alternative moving-average windows, winsorised variables, lagged controls, and the exclusion of the COVID-19 period.

The reported results from the PPML and control-function PPML models are presented as average marginal effects where indicated in the code and manuscript.
